# Jarvis — o'zbek tilidagi ovozli yordamchi

Qo'li ishlamaydigan insonlar telefonni faqat ovoz bilan boshqarishi uchun Android ilova. Tekin, internet faqat ovozni tanish uchun kerak.

## APK'ni olish
GitHub → **Actions** → oxirgi "APK yig'ish" → pastda **Jarvis-APK** → yuklab oling, zipni oching, `app-debug.apk`ni telefonga o'rnating.

## Sozlash
1. "Ruxsatlarni berish" — hammasiga ruxsat bering
2. "Boshqaruvni yoqish" — Accessibility ro'yxatidan **Jarvis boshqaruvi**ni yoqing
3. "Jarvisni ishga tushirish" — so'ng **"Salom Jarvis"** deng
